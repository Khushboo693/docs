**In short:** regplus keeps the basics simple. Turn on **Pro Mode** (the Advanced switch) when you want the more powerful tools. Leave it off for a straightforward event.

## Turn it on

Switch on **Pro Mode** at the **bottom of the left menu**. The Pro modules appear in the menu, each marked with a **PRO** badge.

## What Pro Mode unlocks

| Area | What you get |
| --- | --- |
| **Communications** | Custom emails and WhatsApp templates, confirmations and reminders. |
| **Marketing** | Tracking links, ad pixels, share cards and website embeds. |
| **Event settings** | Team roles, extensions, webhooks and more. |
| **Deeper Insight** | The full set of financial, attendee, traffic and on-ground reports. |
| **Approvals & limits** | Vet registrations before confirming them. |
| **Conditional form questions** | Show questions only when they apply. |
| **Partial registration & private tickets** | Let guests finish later, or sell hidden tickets. |

| Pro Mode | What you see |
| --- | --- |
| **Off** | The essentials — event details, registrations, payments and operations. |
| **On** | Everything, including the Pro modules above. |

<Note>
  Some advanced tools may depend on your plan. If an option is greyed out, check [Plans & billing](/regplus/plans-billing).
</Note>

## FAQs

<AccordionGroup>
  <Accordion title="A module is missing from my menu.">
    Turn on **Pro Mode** at the bottom of the left menu — the Pro modules (marked PRO) only appear when it's on.
  </Accordion>

  <Accordion title="Does Pro Mode change what guests see?">
    No — it only changes which tools **you** see in the dashboard. Your public event page is unaffected.
  </Accordion>
</AccordionGroup>
